How to use antiDrive.

From an empty pendrive to a drive you can open anywhere.

01

Getting started

  1. Download from the download section. antiDrive-0.1.13-stick.zip is the whole pendrive, ready to unzip. The Windows and Linux archives each hold just that system.
  2. Unzip onto the stick. Put the contents at the root of the pendrive. Your files will go in Drive/. App data (database, history, models) goes in .antidrive/.
  3. Run the launcher. On Windows, double-click windows\Run-antiDrive.bat. On Linux, run sh linux/Run-antiDrive.sh. The window opens at http://127.0.0.1:47321/. If that port is taken, the next free one is used.
  4. Set the password. On first run, name the pendrive and create a password of at least 10 characters. The public link never sees this password or the files.
Nothing is installed on the computer. Leave the program running while other devices use the drive.

02

What's on the pendrive

The stick zip unpacks to this tree. Copy it to the root of the pendrive.

stick/
  README.txt
  dist/                 the Drive UI, shared by both systems
  Drive/                your files (created on first run)
  .antidrive/           database, keys, config, history, models (created on first run)
  linux/
    antidrive           static binary: tunnels and transcription are inside
    antidrive-relay     optional relay
    antiDrive.AppImage  the desktop window
    Run-antiDrive.sh  Run-relay.sh  Run-window.sh
  windows/
    antidrive.exe
    antidrive-relay.exe
    Run-antiDrive.bat  Run-relay.bat
  • Linux: start with sh linux/Run-antiDrive.sh, or sh linux/Run-window.sh for the desktop window. The binaries are static, so they run on common distributions without installing anything.
  • Windows: double-click windows\Run-antiDrive.bat. It opens the drive in your browser.
  • .antidrive/device.seed is the drive's identity. Keep it with the drive: deleting it gives the drive a new fingerprint.
  • Files in Drive/ stay ordinary files. Any computer can read them without antiDrive, unless they sit in a vault or you turned on encryption at rest.

03

Going online and sharing

Click Go online. In a few seconds you get a public https link and a QR code. Open it in any browser on any device.

  • The address changes every time you go online. The previous link stops working.
  • The sidebar shows the route that worked, for example Online · Pinggy. Click it to see and copy the full link.
  • Tick Go online automatically when antiDrive starts to skip the click next time.
  • For an address that doesn't change, run your own relay (Run-relay.bat or sh linux/Run-relay.sh) and enter its address under This pendrive → Advanced: a stable address.

Under This pendrive, compare the fingerprint with the one shown on the other computer. A mismatch means stop.

04

Login security

The local window and the public link both ask for the drive password. On the public link, check the fingerprint first: the link carries it after #fp=, and the page refuses to unlock if the key it receives doesn't match.

  • Password, set on first run (10 characters or more) and stored as Argon2id. Change it under This pendrive. Five failures from one address lock that address for 15 minutes.
  • Authenticator codes (2FA). Click Set up authenticator and scan the QR code with any authenticator app. Once on, the code is asked after the password, locally and on the public link.
  • Recovery codes. Generate recovery codes shows them once. Each one unlocks the pendrive a single time, and a new set replaces the old one.
  • Passkeys. Add a passkey for this computer lets Touch ID, Windows Hello or a fingerprint unlock the window. A passkey belongs to one address, so it works on this computer or on a stable hostname of your own (a named tunnel or your relay, including from a phone), not on the changing public link. A passkey already checks the device, so it doesn't also ask for an authenticator code.
  • Active sessions. Sessions last 12 hours. See every signed-in browser, including ones from the public link, and revoke any of them.

Traffic is end-to-end encrypted: files are sealed in the browser and by the program, so the tunnel only carries ciphertext. Share links are the one exception: anyone with a share link can download that file.

05

Working with files

Upload

Click Upload or Folder, or drop files onto the list, from the local window or any device on the link. Big uploads resume where they stopped, and an unfinished upload never shows up as a broken file.

Create any file

The New menu makes Markdown, Text, CSV, Spreadsheet, Document and Folder. It can also Record audio, Record camera, Record screen, and Image, which opens a sketch pad. New text files are called Note.txt, and new CSV files start with a header row.

Readers and editors

Open a file in a tab. Markdown has Read and Edit views and an outline. Text, docx, CSV and xlsx open in editors, where numbers stay numbers and a docx keeps its styles. Google Docs files need exporting as docx first. Every save keeps the previous version.

Player

Audio and video play in a bar at the bottom, with seeking, locally or over the link.

Gallery and lightbox

Gallery shows every image. Click one to open the lightbox: use the arrow keys or the ‹ › buttons to move, and the wheel or + and − to zoom.

Find things

Use the file tree, tabs, Ctrl+O for the quick switcher, Ctrl+K for commands, and the search box. Search looks inside file contents as well as names, so “Lisbon” finds the trip plan that mentions it. A file is indexed once it has been read for its summary. Locked vaults are left out. Starred collects the files you starred.

Look

Under Theme, pick one of ten themes. Each file type has its own colored icon.

06

Transcription

Open a WAV file and click Transcribe. It runs on your own computer, inside antiDrive, and gives the same text every time. The first run downloads the speech model into .antidrive/models/. Export the result as VTT or SRT.

07

Local AI: summaries, Chat and selection

antiDrive’s AI runs on the computer the stick is plugged into, on the CPU. It needs no account and no API key, and it is read-only: it can list, search and read, and it never creates, edits, moves, renames or deletes a file. There is no image generator; New → Image is a sketch pad.

  1. The first time you want AI, open This pendrive → Snapshots and click Download Qwen3 0.6B Instruct. The quantized weights (378 MB, plus an 87 MB search model) download once into .antidrive/models/ on the stick.
  2. That's all. Under CLI you can switch summaries and Chat to an AI command-line tool you already have signed in. It's optional, and it gets the same read-only tools.

Hover summaries

Hover a file to see a card with a preview, a short summary and tags. Summaries are saved in SQLite by path and content hash, so the next hover is instant, and a summary is made again only when the file changes. A very short file shows its own text. Images, audio and video get a description of size, length and format. Summaries never modify the file.

Chat

Chat is Ask only. It finds the files that match your question, answers from their text, and cites each one as [[file name]] so you can open it. Ask “What does the invoice say?” and it answers from invoice.pdf. Locked vaults are left out. If you ask it to change something, it tells you it can't.

Chat runs in the local window. On the public link it's off unless you tick Allow Ask on the public link, and even then it can only read.

Selection popover

In the editor, select text to get Explain, Expand, Simplify, Summarize or Translate. The answer stays out of the document; click Copy to use it.

08

Vaults and encryption at rest

New vault creates a folder with its own password. Its names and contents are sealed on the stick. While locked, it's hidden from search and from Chat. Lock now locks it again. There is no recovery if a vault password is lost.

This pendrive → Files at rest can also seal ordinary files with the drive password. It's off by default, so files on the stick stay readable.

09

History and restore

History is a git repository at .antidrive/history.git, and Drive/ stays a plain folder. Every create, edit, upload, rename, move, delete and restore becomes a commit automatically. Quick edits in a row land in one commit after a few quiet seconds. Each commit records what changed, the paths, who did it (this window, a public link session, or a backup restore), the time and the size of the change.

  • Open History and click a commit to see its files, with a text diff or two images side by side. A file's panel shows the same commits for that file.
  • Restore this version brings back one file. Restore whole drive rolls everything back to that point, and the rollback is itself a new commit.
  • Media, archives and files over 10 MB are stored outside git in .antidrive/blobs and marked stored outside git. A second copy of the same file doesn't take the space twice. Keep last N big versions or N days controls how many large versions are kept.
  • Vault files are committed as the ciphertext already on disk.

10

Backup and restore

Under This pendrive → Backup, type or pick a destination folder on this computer or another drive. Click Backup now, or set a Schedule (every N hours, daily at a time, or a five-field schedule) and click Save schedule. The backup copies your files plus the history repository and the large-file store, and the message says how many files it copied, for example Backup copied 16 files (+ history), skipped 0.

Restore copies the files and their history back onto the stick and records the restore as a commit. Vault files stay sealed in the backup.

11

Troubleshooting

The stick won't run programs (noexec, FAT32, exFAT)

Start it with sh linux/Run-antiDrive.sh. If the stick can't run programs itself, the launcher copies the program to a temporary folder on the computer and runs it from there. Your files stay on the stick.

Go online is slow or uses another route

Go online tries Cloudflare over QUIC, then HTTP/2. If those are blocked, it tries Pinggy on port 443, then localhost.run on port 22. Both use the SSH built into antiDrive, not one installed on the computer. A Pinggy link asks the first visit to continue; refresh if that page stays up. If every route fails, click Retry or use another network.

HEIC photos don't preview

HEIC conversion uses ffmpeg installed on the computer. Install ffmpeg and open the photo again.

Transcribe does nothing for my file

Transcription takes WAV files. Convert other audio to WAV first. A recording made with Record audio is already a WAV.

Test AI fails

Sign in with that command-line tool on this computer, then test again. A tool listed as not installed isn't on this computer's PATH.

12

FAQ

Does anything get installed?

No. Two programs run from the stick, antidrive and antidrive-relay, both written in Rust.

Can the tunnel read my files?

No. It carries only end-to-end encrypted data.

What happens if I unplug the stick?

The drive goes offline. The link works again the next time you start antiDrive and go online, at a new address.

Does it cost anything?

No. antiDrive needs no account and no server. The local AI is a free model that runs on your CPU.

Can several people edit at once?

Not live. Every save is recorded in History, so nothing is lost.

Is it stable?

It's an alpha, 0.1.13. Keep a backup.
