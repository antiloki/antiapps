How it works

One button. No new account.

01

Plug the pendrive in

antiDrive runs on Windows and Linux, from the stick itself. Plug it into any internet-connected PC.

02

Click Go online

One click gives you a public https link and a QR code in a few seconds. Open it on any other machine. No account, no server, and nothing to forward on your router.

03

Sign in and stream

Enter your password, then a code from your authenticator app, or use your fingerprint on this computer or a stable address. Files stream straight off the pendrive, with seeking, end-to-end encrypted. The tunnel can't read them.

Nobody's cloud holds them.

What runs today

Honest about where it is.

  • Portable on Windows and Linux. It runs from the pendrive.
  • Drive-style UI, built with Rust, Tauri and SQLite
  • Streaming with seeking. Files stay on the stick.
  • One-click Go online: a public link with no account and no server
  • Password plus authenticator codes, recovery codes, and passkeys on this computer or a stable address
  • Local AI on the CPU (Qwen3 0.6B): hover summaries, read-only Chat and a selection popover. No API key
  • Editors for txt, markdown, csv, xlsx and docx, with a version kept on every save
  • A player for audio and video, with seeking, even over the public link
  • Transcription of speech to text on your own computer
  • Full-text search inside files, with locked vaults left out
  • Ten themes, from Dracula to GitHub Light
  • Backup to a folder, now or on a schedule, with one-click restore
  • Vaults: folders with their own password, sealed on the stick and hidden from search while locked
  • A new layout: file tree, tabs, a quick switcher (Ctrl+O) and an outline for notes
  • Image lightbox with zoom, and clean Markdown previews
  • Create any file from the New menu: notes, text, CSV, spreadsheets, documents, folders and sketches, plus audio, camera and screen recordings
  • Colored icons for each file type
  • Chat about your files in Ask mode. It reads and answers, and never changes anything
  • Git history: every save is a commit. Restore one file or the whole drive, with big files stored outside git
  • 100% Rust: two programs on the stick, with nothing else to install
  • Alpha 0.1.13. Linux and Windows are up. Works on locked-down networks too: if Cloudflare is blocked, it falls back to a link on port 443.
