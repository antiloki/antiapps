01

Overview

antiPost is a desktop app for posting, answering comments and DMs, and capturing leads without opening Instagram, X or YouTube. Your agents are coding CLIs you already pay for: Codex CLI, Claude Code, Grok CLI, Cursor Agent CLI or Gemini CLI. They work through a local MCP server. Nothing is published or sent until you approve it.

App data lives in one SQLite file. Secrets live in the OS keychain. It is built in Rust with Tauri 2.

antiPost is an early build (0.1.7). Approving a reply records the text; sending through the networks is not wired up yet. planned

02

Install

Public downloads are not available yet. planned Builds are planned for Windows, macOS (Apple silicon and Intel) and Linux (deb, rpm, AppImage).

To run from source you need Rust (the repo pins its toolchain). Linux also needs WebKitGTK 4.1:

sudo apt-get install -y libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev \
  librsvg2-dev patchelf build-essential pkg-config libssl-dev
cargo run -p antipost

There is no Node build. The interface is static files embedded in the app.

03

First launch

The setup wizard walks through:

  1. Which agent CLIs are installed.
  2. Your first agent and its working folder.
  3. A brand name and one URL.
  4. Optional X, Instagram and YouTube connections.

Each agent runs its CLI in a terminal session confined to its folder. Output streams into the chat and is saved in SQLite.

04

Connecting X, Instagram and YouTube

Settings → Connections shows a card per network.

StatusMeaning
Not set upantiPost does not have that network's developer app yet. Connect opens a short setup wizard.
App configuredThe client id is saved and, when needed, the secret is in the OS keychain.
Connected as @nameYou finished Connect and the network returned that account.

The wizard opens the provider's console and gives one-click copy for the callback URL and each scope. Paste the client id and secret, press Test, then Finish. Nothing is saved until Finish. Connect opens your system browser.

The redirect port is 43827. If it is taken, Connect stops and nothing is saved. Reset removes the saved id, the keychain secret and the account token.

05

Inbox, posts and approvals

The app has an Inbox, Posts (list and board), Leads, Calendar, Analytics and Connections, plus an agent list with a chat per agent and a ⌘K palette.

Agents draft replies and posts. You approve, edit or discard them. There is no approve tool for agents, so only you can approve.

06

Brand, audience and trends

Brand notes and fetched page excerpts are kept in SQLite, and your chosen agent drafts the brand profile. Audience, trend and engagement reads use the networks' official APIs only when credentials are saved; otherwise the screen says what is missing.

07

Leads from antiHunt

Settings → Integrations → antiHunt reads antiHunt's SQLite file, read-only. antiPost never writes to it.

Default file locations:

  • Linux: ~/.local/share/com.minemylead.antihunt/antihunt.db
  • macOS: ~/Library/Application Support/com.minemylead.antihunt/antihunt.db
  • Windows: %APPDATA%\com.minemylead.antihunt\antihunt.db

Paste another path if yours is elsewhere. Sync now imports leads; the same platform and handle update one lead. Set an interval in hours to sync when Leads is opened, or 0 to sync only by hand. Hot and warm leads can be queued for Engage, where the agent drafts a reply in your brand voice for you to approve.

08

MCP tools for agents

A local MCP server on the loopback address exposes tools for drafts, the inbox, leads and tasks, plus read-only brand, audience, trend and engagement tools. Each agent gets its own bearer token, stored in the OS keychain.

09

Data and privacy

Everything is in one SQLite file on your computer. Credentials, OAuth tokens and MCP tokens go to the OS keychain and are never written to SQLite. Secrets are never compiled into the app.

10

Troubleshooting

Connect says the port is taken

Another program uses port 43827. Close it and try again.

Leads says antiHunt is not installed

antiHunt's database was not found at the default path. Paste the full path to antihunt.db.

Analytics shows what is missing

Connect that network first; reads use only official APIs.
