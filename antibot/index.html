antiBot · local-first desktop app

Many agents. One table. You hold the scalpel.

A multi-agent desktop assistant that runs entirely on your computer. Each agent is a persistent chat backed by an AI CLI you already have installed and signed in to. There is no server and no API key field.

How it works

Three steps. No new account.

01

Create agents

Each agent gets its own workspace folder and its own provider: Claude Code, Codex CLI, Gemini CLI or any custom command.

02

Give them memory and routines

Per-agent notes and a shared memory about you go into every prompt. Scheduled routines run in the background and post results into the chat.

03

Let them work together

Agents message each other, with a hop limit that stops loops. Every turn becomes a task with an id, a status and an audit log.

Stop babysitting bots.
